    尚未連線雲端同步

    A. 進度碼（手動備份／搬移）

    在一台裝置按「匯出」，把整串文字傳到另一台（例如 LINE 傳給自己），再按「匯入」貼上。

    B. GitHub Gist 自動同步

    1. 到 GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token。
    2. 只勾選 gist 權限，設定到期日後產生，複製 token。
    3. 貼在下面按「連線」。第二台裝置貼同一組 token 即可，會自動找到同一個 Gist。

    已連線 Gist：

    每次存檔後約 3 秒自動上傳；打開網頁或切回分頁時自動下載並合併。
